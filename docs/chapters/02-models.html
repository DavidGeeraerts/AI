2.11 Model families and access

The landscape includes models from Anthropic (Claude), OpenAI (GPT), Google DeepMind (Gemini and Gemma), DeepSeek, Alibaba (Qwen), Meta (Llama and Muse), xAI (Grok), Moonshot (Kimi), Mistral, and Zhipu (GLM). Open-weight and closed models differ in how they can be inspected, hosted, adapted, and accessed.

2.12 Evaluation and training data

Benchmarks help compare models, but scores need context. Some benchmarks, such as MMLU and GSM8K, are nearing saturation; others, including SWE-bench variants, LiveBench, LMArena, GAIA, and BenchLM, provide different signals. Training data sources such as Common Crawl and FineWeb also shape model capabilities.

2.13 Abliteration

Refusal-removal techniques and fine-tunes, including Heretic and Ajax, can change how a model responds. Consider their impact on behavior and agent autonomy when selecting a model.

2.15 Benchmarks

Benchmark Status in 2026 Strengths Weaknesses Still useful?
MMLU Saturated Historical reference for broad knowledge Frontier models cluster ~90%+; little differentiation; contamination risk Mostly no (use MMLU-Pro if needed)
GSM8K Saturated Simple math word problems Top models near ceiling (~95%+); many invalid questions noted No for frontier comparison
GPQA (Graduate-Level Google-Proof Q&A Benchmark; esp. Diamond) Near-saturating Challenging multiple-choice benchmark evaluating advanced scientific reasoning and deep domain understanding in large language models Leaders pushing 90%+; small set → noise Still decent for science reasoning, but headroom shrinking
SWE-bench (Verified/Pro variants) Contested / partially saturating Real GitHub issue resolution; strong signal for coding agents Contamination concerns; scores climbing into high 70s–90s on easier versions Yes for coding/agentic work (prefer newer/harder variants like Pro)
GAIA Active but contested Multi-step agentic tasks (browsing, tools, files) that are easy for humans Large score gaps depending on scaffolding/tools; some saturation reports Yes for assistant/agent evaluation
LiveBench Highly regarded Monthly-refreshed questions from recent sources; objective ground-truth scoring; covers reasoning, coding, math, data analysis, language, instruction following Not human preference; not pure agentic long-horizon One of the strongest current objective capability benchmarks
LMArena (Chatbot/Arena) Highly regarded Large-scale blind human preference (Elo-style); real user prompts Style/verbosity bias; overlapping confidence intervals; not verifiable correctness Best for “which model feels best in open-ended use”
BenchLM Aggregator Combines many sources into overall indices Depends on underlying benchmarks; not a primary eval itself Useful meta-view, not a standalone benchmark
Mensa Norway IQ Test Niche Attempts IQ-style scoring Narrow, not standard in frontier AI evaluation Rarely used for serious model comparison
WebDev Arena Specialized Web development tasks Narrow domain Useful only if you care specifically about web-dev agents
Humanity’s Last Exam (HLE) Active frontier benchmark Expert-authored (≈1,000 contributors) multi-modal closed-ended questions (2,500 total) at the frontier of human knowledge across 100+ subjects; designed to resist search/contamination; objective grading; HLE-Diamond & Rolling variants for continued headroom Score variance across full set / text-only / Diamond / with-tools; some answer-key disputes (esp. chem/bio); calibration remains poor Yes — currently one of the strongest non-saturated academic/knowledge + reasoning benchmarks
WorkBuddy Bench (Tencent) Active / Research Preview (v1.2, Oct 2026) Multi-domain coding-agent eval (Code 80 / Web 70 / Office 50 / Security 60 tasks) reverse-engineered from real work; contamination-resistant prompts; dual harnesses (CodeBuddy Code + Claude Code); fully open (tasks, Docker images, tests, solutions); reports efficiency (tokens/turns) No suite-wide average (subset scores incomparable); harness effects are large; still early / Research Preview; heavier compute than pure unit-test benchmarks Yes — one of the strongest current multi-domain agentic coding benchmarks, especially for real-world role-played work beyond pure SWE-bench-style issue fixing
Artificial Analysis Intelligence Index v5 Active frontier composite (launched Oct 2026) Independent composite of 9 hard evaluations (Knowledge Work / Coding / Science / General at 25% each); 60% private or held-out data to resist contamination; strong agentic emphasis (FrontierCode 2.0, Terminal-Bench-Science, AA-Briefcase); no single model dominates all components Version scores not comparable to prior AA indices; heavy reliance on private tests reduces external auditability; mainly English text-only; effort settings and harness can shift rankings significantly Yes — currently one of the most-watched single-number frontier rankings for overall capability, especially agentic/knowledge-work + coding
Terminal-Bench Active (2.x line) Real command-line tasks in sandboxed containers (builds, debugging, sysadmin, data work); tests end-to-end agent behavior, not just code output; open tasks and harness; widely cited by labs and composite indices Results depend heavily on the agent harness; tasks vary in difficulty and flakiness; long-running and compute-heavy Yes — a core benchmark for terminal and coding agents
τ-bench / τ²-bench (Sierra) Active Tool-using agents in multi-turn conversations with a simulated user under domain policies (retail, airline, telecom); pass^k metric measures consistency across repeated runs Simulated-user behavior adds noise; narrow customer-service domains; some task and label errors reported Yes — one of the best tests of policy-following, reliability, and tool use in conversation
OSWorld (incl. OSWorld-Verified) Active, scores rising fast Agents operate real desktop operating systems and apps (Ubuntu, Windows, macOS) through screenshots and mouse/keyboard; execution-based checking; human baseline about 72% Slow and costly to run; environment setup and flaky tasks; scores sensitive to screenshot resolution and step limits Yes — the standard benchmark for computer-use agents
BrowseComp (OpenAI) Active, climbing 1,266 hard-to-find but easy-to-verify questions that need persistent, creative web browsing; short answers allow objective grading Answers can leak onto the web over time; measures finding facts, not synthesis or report quality; English-centric (BrowseComp-ZH covers Chinese) Yes — the go-to benchmark for deep-research and web-browsing agents
MCP-Universe (Salesforce) and other MCP benchmarks (MCP-Bench, MCPMark) Emerging Agents use real Model Context Protocol servers (GitHub, maps, finance, browser, etc.) on multi-step tasks; execution-based checking; directly mirrors how modern agents connect to tools Young and fragmented, with no single standard; depends on live third-party services that change; long-context and unfamiliar-tool challenges skew results Yes, if you build MCP-based agents — watch for consolidation
METR Time Horizons Active, widely cited Measures the length of tasks (in human expert time) an agent completes with 50% reliability; tracks the trend over time (roughly doubling every ~7 months); grounded in software and research tasks Wide confidence intervals; task suite skews toward software and ML; 50% reliability is far below production needs; not a leaderboard of everyday performance Yes — the best single measure of how autonomous agents are becoming
ARC-AGI (ARC-AGI-2 / ARC-AGI-3) Active, far from saturated on newer versions Novel visual grid puzzles that test abstraction and skill acquisition on unseen problems; easy for humans, hard for models; cost-per-task reported alongside scores; ARC-AGI-3 adds interactive game-like environments Narrow puzzle domain; results swing with test-time compute budgets; limited direct transfer to agentic work Yes — the leading test of genuine novel reasoning rather than memorization
Aider Polyglot Near-saturating at the top 225 hard Exercism exercises across C++, Go, Java, JavaScript, Python, and Rust; tests the model’s ability to make correct edits in a real coding workflow; reports cost and edit-format compliance Exercise-style problems, not real repositories; public exercises raise contamination risk; top models cluster high Somewhat — useful for comparing code-editing reliability and cost; less so at the frontier

2.16 Model Training Data

2.16.1 Pretraining Corpora

(Order by Name ↑)

  • C4 (Colossal Clean Crawled Corpus) – cleaned Common Crawl text used to train T5 and many later models.
  • Common Crawl – the raw open web crawl underlying most pretraining datasets.
  • Dolma (Ai2) – fully open pretraining corpus behind the Olmo models.
  • FineWeb – curated, deduplicated Common Crawl dataset.
  • FineWeb-Edu – educational-quality subset of FineWeb.
  • FineWeb 2 – multilingual extension of FineWeb.
  • LAION / Re-LAION-5B – large image-text pair dataset used to train image models such as Stable Diffusion.
  • RedPajama (Together AI) – open reproduction of the LLaMA training data mix.
  • The Pile (EleutherAI) – diverse 800 GB English text corpus from 22 sources.
  • The Stack v2 (BigCode) – large permissively licensed source-code dataset; key for code and agentic models.

2.16.2 Post-Training and Agent Datasets

(Order by Name ↑)

  • Dolci (Ai2) – supervised fine-tuning data for Olmo Think and Instruct models, including tool-use sets.
  • SWE-Gym – environment and agent trajectories for training software-engineering agents on real GitHub tasks.
  • SWE-smith – toolkit and dataset for generating software-engineering tasks and coding-agent trajectories at scale.
  • Tulu 3 (Ai2) – open instruction-tuning and preference data, with recipes.
