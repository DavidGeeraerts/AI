# Quarto Publishing

Use this skill when authoring or updating the Quarto website.

- Edit the `.qmd` source files rather than generated HTML in `docs/`.
- Check `_quarto.yml` and the applicable `AGENTS.md` instructions before changing the site structure or build workflow.
- Keep generated output in `docs/` synchronized when rendering is part of the requested change.
